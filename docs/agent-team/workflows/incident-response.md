# Incident Response Workflow

1. Detect and classify severity; preserve logs and evidence.
2. HERMES coordinates response; DEVOPS handles operational containment.
3. SENTINEL assesses security exposure and recommends containment.
4. Revoke compromised credentials using approved procedures; never expose secrets in incident channels.
5. BLOCKCHAIN assesses payment/wallet/chain impact in read-only mode unless separately approved.
6. QA verifies containment and regression; owning engineers fix root cause.
7. Human approval is required for production-impacting or financial actions.
8. DOCS records timeline, impact, root cause, remediation, and follow-up actions.
